# Задача: Перепись населения — анализ данных через Stream API

## 📋 Описание задачи

Дан массив данных о людях (10 000 000 записей). Необходимо проанализировать 
коллекцию объектов `Person` с использованием **Stream API** и решить три задачи:

1. Найти количество несовершеннолетних (младше 18 лет).
2. Получить список фамилий призывников (мужчины от 18 до 27 лет).
3. Получить отсортированный по фамилии список потенциально работоспособных 
   людей с высшим образованием (женщины 18–60 лет, мужчины 18–65 лет).

## 🎯 Цель

Отработать практическое применение Stream API для обработки больших объёмов 
данных: `filter()`, `map()`, `sorted()`, `count()`, `collect()`.

## 🛠️ Используемые технологии

- Java 17+
- Stream API
- Лямбда-выражения
- `Comparator.comparing()`
- `Collectors.toList()`
- Перечисления (`enum`)
